# Rock Paper Scissors Game

A simple Rock Paper Scissors game made with Python and Tkinter.

I made this project to practice GUI development in Python. It's easy to play and runs on any system with Python.

## Features
- Simple and clean UI
- Play against computer
- Live scoreboard
- Reset button to restart the game

## Built With
- Python
- Tkinter

## How it Works
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- If both choose same, it's a tie
